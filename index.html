Speed Hack Detection

Server-side velocity checks compare actual character displacement per tick against the physics-allowed maximum. Clients cannot fake server-side math.

-- Server checks real distance traveled
local dist = (char.HumanoidRootPart.Position
  - lastPos).Magnitude
if dist / dt > MAX_SPEED then
  flagPlayer(player, "SpeedHack")
end
🔒

Remote Event Validation

Every RemoteEvent fired by a client is treated as untrusted. All inputs are validated server-side — type, range, rate, and cooldown.

-- Never trust the client
RemoteEvent.OnServerEvent:Connect(
  function(player, data)
    if type(data) ~= "number" then return end
    if data < 0 or data > MAX_VAL then return end
    -- safe to use data
  end
)
🛡️

Teleport Detection

Detects impossible position jumps between ticks. Flags players whose CFrame changes by more than the physics engine allows in one frame.

-- Flag impossible position jumps
local jump = (newPos - oldPos).Magnitude
if jump > MAX_JUMP_DIST then
  flagPlayer(player, "Teleport")
end

Anti-Cheat Logging

All flag events are logged with timestamp, player ID, violation type, and severity. Multiple flags trigger automatic kicks and admin alerts.

local function flagPlayer(p, reason)
  logs[p.UserId] = logs[p.UserId] or {}
  table.insert(logs[p.UserId], {
    reason = reason,
    time   = os.time()
  })
  checkThreshold(p)
end
