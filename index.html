Detection

Speed Hack Detection

Server-side velocity checks compare actual displacement per tick against the physics max. Clients can't fake server-side math.

Luau 
local dist = (char.HumanoidRootPart.Position
  - lastPos).Magnitude
if dist / dt > MAX_SPEED then
  flagPlayer(player, "SpeedHack")
end

Validation

Remote Event Validation

Every client-fired RemoteEvent is treated as untrusted. All inputs validated server-side — type, range, rate, and cooldown.

Luau 
RemoteEvent.OnServerEvent:Connect(
  function(player, data)
    if type(data) ~= "number" then return end
    if data < 0 or data > MAX_VAL then return end
    -- safe to process
  end
)

Detection

Teleport Detection

Flags impossible position jumps between ticks. Catches players whose CFrame changes more than physics allows in one frame.

Luau 
local jump = (newPos - oldPos).Magnitude
if jump > MAX_JUMP_DIST then
  flagPlayer(player, "Teleport")
end

Anti-Cheat Logging

All flag events logged with timestamp, player ID, violation type, and severity. Multiple flags trigger auto-kick and admin alerts.

local function flagPlayer(p, reason)
  logs[p.UserId] = logs[p.UserId] or {}
  table.insert(logs[p.UserId], {
    reason = reason, time = os.time()
  })
  checkThreshold(p)
end
